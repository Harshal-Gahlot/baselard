# Project map

## Central configuration
- `src/config/experience.ts` — **only homepage variant selector**. Current selections: hero `sonic`, projects `editorial`, credits `wall`, capabilities `index`, studio `split`, testimonials `feature`, contact `statement`.
- `src/config/site.ts` — site metadata, contact coordinates/links, social profiles.
- `src/data/studio.ts` — service taxonomy, press outlets, collaborators, testimonials, founder/studio story.
- `src/data/projects.ts` — curated project archive, merged YouTube uploads and discovery links.
- `src/data/generated/youtube-releases.ts` — generated by `bun run sync:youtube`; review this feed before publishing.
- `scripts/sync-youtube.mjs` — optional local YouTube Data API sync; requires private `.env` credentials.

## Pages
- `src/pages/index.astro` — assembles the homepage from the switch wrappers.
- `src/pages/work.astro` — project archive and filters.
- `src/pages/services.astro` — detailed services.
- `src/pages/studio.astro` — Udaipur facilities.
- `src/pages/story.astro` — founder/studio timeline.
- `src/pages/press.astro` — media features and awards.
- `src/pages/contact.astro` — enquiry form and contact routes.
- `src/pages/404.astro` — not-found state.

## Shared components
- `src/layouts/BaseLayout.astro` — SEO, fonts, navigation lifecycle, global stylesheet.
- `src/components/global/` — header, footer, section heading, project card.
- `src/components/sections/<section>/` — one `<Section>Switch.astro` wrapper plus up to three visual alternatives.
- `src/scripts/site.ts` — mobile nav, scroll reveal, archive filtering, mailto form enhancement.
- `src/styles/global.css` — tokens, responsive primitives, shared motion, typography.
